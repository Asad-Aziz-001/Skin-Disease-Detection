## 🌟 Overview

**DermaScan AI** is a clinical-grade, AI-powered web application that enables rapid and accurate detection of **31 skin diseases** using the cutting-edge **Google BiT (Big Transfer)** model — fine-tuned on a curated dermatology dataset of 10,000+ images.

Built with a **Flask** backend and a fully responsive frontend, this system provides real-time predictions, visual analytics, history tracking, and PDF report generation — all inside a secure, authenticated environment.

## 💻 Installation & Setup

### 📋 Prerequisites

```bash
✅ Python 3.10+
✅ pip (Python package manager)
✅ Git
✅ 4GB+ RAM (for model loading)
✅ CUDA GPU (optional, for faster inference)
```

### 🔧 Step-by-Step Setup

**Step 1 — Clone the Repository**
```bash
git clone https://github.com/Asad-Aziz-001/dermascan-ai.git
cd dermascan-ai
```

**Step 2 — Create Virtual Environment**
```bash
# 🪟 Windows
python -m venv venv
venv\Scripts\activate

# 🐧 Linux / 🍎 macOS
python3 -m venv venv
source venv/bin/activate
```

**Step 3 — Install Dependencies**
```bash
pip install -r requirements.txt
```

**Step 4 — Run the Application**
```bash
python app.py
```

**Step 5 — Open in Browser**
```
🌐  http://localhost:5000
```
